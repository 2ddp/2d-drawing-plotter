# 不具合報告・機能要望 / Reports and requests

表示、DWG互換性、PDF出力の不具合と機能要望をIssuesで受け付けています。バージョン、Windows・ブラウザーの種類、再現手順、期待する結果、実際の結果を記載してください。

機密図面、個人情報、未修正の脆弱性の詳細を公開しないでください。添付資料は公開可能な内容に限ります。

本体ソースコードは公開しておらず、本体へのPull Requestは受け付けていません。説明書の訂正もIssueでお知らせください。

English: Use Issues for bugs and requests. Include version, environment, reproduction steps and expected/actual results. Attach only material you may make public. Do not disclose confidential drawings or unpatched vulnerabilities. Application source and application pull requests are not offered.
