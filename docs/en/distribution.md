# Distribution and notices

The runtime ZIP includes official Python 3.13.16 x64, application Python bytecode/minified JS, pinned parser/libraries/fonts and notices/manuals. Executable browser JS remains inspectable. Maintained source, maps, tests, logs and history are excluded.

The matching LibreDWG source ZIP includes the complete pinned upstream source, Unicode patch, independent CLI build instructions/configuration and notices, but no application source. Publish it with equivalent access at the same place and no extra charge alongside the runtime. BUILD-INFO records its exact name and SHA-256. An upstream-only link is not substituted.

Private-Development.zip contains private maintenance/recovery source and must not be publicly distributed. No Git history is included. Proposed application terms do not override third-party licenses or revoke prior MIT grants. Public release remains gated on GPL boundary/ownership/name/attribution review, Windows acceptance and configuring private security reports.
