# 既知の制約

## 対応範囲

| 対象 | 現在の範囲・制約 |
|---|---|
| DWG | LibreDWG 0.13.4のfull JSONから独自モデルへ変換。DXFを経由しません |
| 図形 | LINE、円・円弧、楕円、2Dポリライン、幅・bulge、スプライン、SOLID、点 |
| Block／属性 | 入れ子・座標変換、基本INSERT、ATTDEF／ATTRIB。XREFの追加ファイル読込なし |
| HATCH／LEADER | 基本境界、ベタ・連続線パターン、基本引出線と主要スタイル。特殊機能は診断 |
| 寸法 | 保存済み描画Blockを使用。寸法再生成はなし |
| Layout／Viewport | 矩形・上面表示と基本freeze。非矩形／透視・詳細VP属性は制約 |
| 文字 | TEXT、基本MTEXT書式・配置・積み文字、SHX横書きと代替TrueType |
| 画層／操作 | 表示・印刷の独立チェック、選択画層の強調、Viewport内選択、移動・ズーム |
| スナップ | 基本図形の端点・中点・中心・四半円点と矩形Viewport枠。全CADスナップ互換ではありません |
| Plot／PDF | 用紙、向き、余白、尺度、矩形・表示範囲、CTBペン、SHX検索、文字サブセット |
| 保存 | 明示的な設定v3書出し、旧設定読込、独自モデルJSON。DWG編集・保存なし |

複雑線種、透過性、VP別属性、詳細文字組版、非矩形Viewport、寸法再生成、特殊ハッチ、非ゼロthicknessの立体化、プロキシ等は完全互換ではありません。受付DWG世代は全ファイルの正しい解析・描画を保証しません。未対応・代替は診断へ記録します。

注釈は読取専用・ロックフラグを使用しますが、PDFソフトの処理に依存します。可視／検索文字のクリップ境界の扱いにもソフト差があります。Sceneの上限に達した場合は部分PDFを出力しません。
