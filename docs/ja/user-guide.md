# 使い方

2D Drawing Plotter 0.1.1。Windows 11 x64向け、2D表示・PDF出力専用です。主言語は日本語です。英語の説明書を併置していますが、画面の英語切替はまだありません。

## 初回準備と起動

1. Windows-x64.zipを自分が書込みできるフォルダーへすべて展開します。
2. 同梱のruntime/python.exeとserver/main.pycを保持したまま、START.cmdをダブルクリックします。
3. ブラウザとサーバーのコンソールが開きます。作業中はコンソールを開いたままにします。終了時はタブとコンソールを閉じます。

公式Python 3.13.16 x64を同梱します。Git、Node.js、pip、Pythonのインストール・手動取得、管理者権限は不要です。旧版のruntimeフォルダーへの置換は行わず、必ず新しいフォルダーへ全体を展開してください。

Edge、Chrome、Firefoxのデスクトップ版を対象とします。図面は127.0.0.1のローカルサーバーで解析します。

## 図面を開く・操作する

「DWGを開く」、または図面表示エリアへのドラッグ＆ドロップで読み込みます。ドロップはDWGファイル1つずつに対応します。入力上限128MB、解析時間上限120秒です。「表示するビュー」でModel／Layoutを選択します。

図面の右中央バーで選択／移動、拡大縮小、全体表示を操作します。中ボタンのドラッグで移動、ホイールで拡大縮小します。印刷矩形の選択中も利用できます。

選択モードではクリックと右ドラッグで選択します。右向きの矩形は全体包含、左向きは交差選択です。Shiftで追加、Escで解除します。ビューポート内の図形も対象です。文字の選択は外接矩形による判定です。

左側の画層リストは表示／印刷を別々に設定します。選択した要素の画層を強調表示します。画面が非表示でも、印刷オンの画層はPDFの対象です。元DWGへ書き込みません。

## PDFを保存する

- 用紙はA0〜A4／任意サイズ、縦横を選択します。定形用紙の幅・高さは自動計算で編集不可です。
- 出力範囲は印刷対象全体／現在の表示範囲／選択した矩形です。矩形は2点で指定し、スナップをチェックまたはAltで解除できます。
- 余白は「ページ設定の詳細」にあり、初期値0mmです。出力は中央配置です。
- 尺度は用紙合わせ／1:nの指定です。用紙合わせでは計算値を表示し編集不可です。はみ出す場合だけ切取り警告を尺度欄に表示します。
- 図面・レイアウトの単位を自動使用します。未指定時はmmを仮定するため診断を確認し、必要な場合だけ詳細の単位補正を使用してください。

「PDFを保存」から直接保存します。PDFプレビュー機能はありません。

## ペン・色・CTB

出力色は黒（初期値）／図面の使用色／色別設定です。「出力色・線幅」内の「CTB・色別設定」からCTBを読み込み、使用ACIの出力色・線幅・印刷濃度を調整できます。

一覧の連番は表示順です。元のCAD色番号ACIは変更しません。TrueColorはACIペンの対象外です。出力色はRGB（初期値）／HSL／HEX／パレット／画面スポイトで指定します。図面色へ戻す操作も同じ画面にあります。

Windowsの画面スポイトはカーソル周囲のピクセルを拡大表示します。ブラウザの画面取得を使用する場合は共有の許可が必要です。操作を取り消せます。

印刷濃度は白との混色率であり、不透明度とは異なります。CTBの色・線幅・印刷濃度・グレースケールを扱います。図面の使用色ではペンの色・グレースケール上書きを適用せず、線幅と印刷濃度は維持します。全体のグレースケール選択UIはありません。

CTBの線種・線端・結合・パターン等の上書きには制約を診断で表示します。STBは読み込みません。

## フォントと検索

「SHXフォント」から利用可能なSHXを読み込むと、対応する文字を細線ベクターで表示・出力します。フォントは自動取得しません。同梱する代替フォントはNoto Sans JPです。不足・未対応字形の代替理由は診断に表示します。

SHXはSHAPES 1.0/1.1、UNIFONT 1.0、BIGFONT 1.0の横書きを対象とします。BIGFONTはShift-JIS前提です。縦書き、全製品・特殊亜種の完全互換はありません。フォント読込は1ファイル16MB、合計64MB、64個までです。タブを閉じると解除し、設定JSONへフォント本体は保存しません。

SHX文字線幅は専用値（初期0.10mm）または図形ペンを選択します。TrueTypeの塗りつぶし字形の太さは変更しません。

SHXの検索追加方式は透明文字／注釈／なしです。TrueTypeは「なし」でも通常の文字として検索できます。使用字形だけをPDFへサブセット埋込みします。検索・コピー・注釈検索の挙動にはPDFソフト差があります。同梱フォントにない可視／透明文字は黙って欠落させず、出力を中止します。

## 設定とJSON

設定は「設定を書き出す」の操作時だけ保存します。図面別の自動保存はありません。ペン・用紙・スナップ・同名画層を再読込できます。矩形、選択ビュー、図面IDは保存しません。旧設定v1と独立形式v1〜v3を読み込み、書出しはv3です。

「解析JSONを開く」はLibreDWG 0.13.4 full JSON用です。「解析JSONを保存」は診断を含む独自DrawingDocumentを保存します。両者は別形式で、保存した独自モデルは現時点ではそのまま再読込できません。JSONも図面の内容を含むため、公開しないでください。

## エラー時

「診断」は同じ原因を1行にまとめて表示します。警告・情報の数は原因の種類数で、対象件数も別に表示します。複数の要素が対象の場合は「n 要素」を展開してIDを確認できます。解析JSONの保存には各要素の診断を含みます。

初回runtime不足はREADME.htmlの準備手順を確認します。ファイル不足・内容不一致は配布ZIPを新しいフォルダーへ再展開してください。既存の実行中フォルダーへ上書き混在させないでください。

図面を開けない場合は対応DWG世代・サイズ・解析時間を確認します。表示やPDFの欠落については上部の「診断」を確認してください。描画件数の上限に達した場合は部分PDFを出力しません。

押し出し厚さが2Dの輪郭へ影響しない場合は情報として表示します。ブロックの傾きなどで輪郭が変わる場合は警告を残します。判定はDWGの読み込み時に取得した厚さ・方向に基づきます。

直線・円弧で構成される一定幅の開いたポリラインは、破線の切れ目と図面単位の幅を持つベクターで描画・PDF出力します。曲線の接合を近似する場合は診断で確認できます。MTEXTの下線・上線・取消線も共通のベクター描画です。

旧形式の曲線・スプライン補間付きポリラインは、保存済みの描画頂点を利用します。スプラインの制御枠は描画線やスナップ対象に含めません。頂点の役割情報を持たない古い解析JSONは、元DWGを開き直して更新してください。

背景マスク（WIPEOUT）は画面の背景色、PDFでは白で背後の図形を隠します。保存された重なり順と枠の表示・印刷設定を使用します。枠が「表示のみ」の場合はPDFへ出力しません。マスクの画層も表示／印刷の設定に従います。

MTEXTの字間指定（0.75〜4倍）は、文字位置、折り返し、積み上げ文字、下線・上線・取消線に反映されます。文字の形を横に伸ばす設定とは別です。未対応の書式は診断から確認できます。

MTEXTの部分色（色番号・RGB）を画面とPDFに反映します。色番号指定は色別ペン設定の対象です。
