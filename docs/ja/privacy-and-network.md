# 通信・保存の実装範囲

## アプリの通信

Python HTTPサーバーは127.0.0.1のランダムポートだけで待受けます。Hostを検証し、POSTには同一Originとセッショントークンを要求します。ログはローカルコンソールへのHTTP要求情報です。

ブラウザのfetchは/api/status、/api/parse、/api/ctb、/api/picker、/api/pick、/api/pick-cancelと同梱TTFだけです。PDFのライブラリ、CSS、JS、フォントは相対パスから取得します。WebSocket、テレメトリ、自動更新、CDN、外部フォント取得は実装していません。

CSPはスクリプト・接続・フォントを同一Originに制限します。Pythonの監査フックはこのプロセスの外部connect・bind・名前解決を拒否します。これらはOS全体のファイアウォールではなく、別プロセスの解析器やブラウザ自身の通信を包括的に保証しません。

## ファイルと画面

DWGの解析コピーとJSONはOS一時フォルダーで処理し、通常の終了・例外で削除します。強制終了では残存し得ます。フォントはタブ内のメモリに保持し、外部取得しません。画面スポイトは明示操作時だけ取得します。PDF・JSON・設定はブラウザの保存先へ明示保存します。入力DWGへ書き込みません。

## 検証の範囲

静的参照検査、外部connect拒否テスト、ローカルHTTP/API、実行用JSでの操作・PDF生成を開発環境で検証します。Windows Firewall/TCPView/Wireshark等による全操作の実機通信監視、オフライン起動と受入は未実施です。ブラウザ・OSの独立通信は別途切り分けて記録します。将来変更した場合は本資料を更新します。
