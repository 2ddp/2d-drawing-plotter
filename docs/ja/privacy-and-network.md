# 通信と保存

図面の解析・表示・PDF生成はPC内で行います。必要なプログラム、ライブラリ、代替フォントは配布物に同梱しており、すべての機能をインターネット接続なしで利用できます。自動更新確認・広告・テレメトリは実装していません。

ブラウザーとアプリは127.0.0.1のローカル接続で通信します。ブラウザー・OS独自の同期や更新は、それぞれの設定に従います。

解析用一時ファイルはOSの一時領域に作成し、通常終了時に削除します。強制終了時は残る場合があります。PDF・設定・解析JSONは保存操作時に保存します。元のDWGを書き換えません。

画面スポイトは利用者の操作時だけ画面の色を取得します。取得した画面を外部送信しません。
