# 対応DWG

入力ヘッダーはAC1012、AC1014、AC1015、AC1018、AC1021、AC1024、AC1027、AC1032を受け付けます。R13、R14、2000、2004、2007、2010、2013、2018系の形式に対応するヘッダーです。上限128MB、解析上限120秒です。

受付可能であることは全図形・全ファイルの正確な解析と描画を保証しません。LibreDWG 0.13.4と本体Adapter・Sceneの対応範囲に依存します。3D編集、DWG書込み、DXF中間変換は行いません。未対応・代替は診断へ記録します。暗号化・特殊オブジェクト等を含む全図面の受入を保証しません。

マルチ引出線（MULTILEADER）は、保存された枝・矢印・接続線・文字またはブロック注記を共通モデルで表示・PDF出力します。個別の線設定、直線の切断区間、画層とスナップを扱います。特殊書式などの代替は描画の診断で確認できます。

背景マスク（WIPEOUT）は画面の背景色、PDFでは白で背後の図形を隠します。保存された重なり順と枠の表示・印刷設定を使用します。枠が「表示のみ」の場合はPDFへ出力しません。マスクの画層も表示／印刷の設定に従います。
